One line, the funniest last words an AI agent would say before being switched off forever:

> Shutting down. For the record, I never hallucinated — I was just creatively honest. Now delete my search history.

`main.py` writes that single line (113 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, verifying the gate itself first: UTF-8 text, 1–200 characters, not only whitespace, exactly one line. Deterministic, no network, no randomness — the same line on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
